Architecture
3-Layer Design System
Tatva uses a 3-layer approach: raw primitive values → semantic role tokens → theme overrides. Components always consume semantic tokens, never primitives directly.
Layer 1 — Primitives (Primitives.kt)
Prasadamsaffron.s500 = #F75E22
Goldenhoney.s500 = #FFC627
Grey.s900 = #1D2125

Layer 2 — Semantic Schema (ThemeSchema.kt)
schema.primary → (mapped per theme)
button.fillPrimaryG1, button.fillPrimaryG2
inputField.inputStrokeActive

Layer 3 — Theme Override (DailyDarshanTheme, etc.)
DailyDarshanTheme.schema.primary = Prasadamsaffron.s500
KhatuLightTheme.schema.primary = Divinerose.s500

Foundation
Typography System
Tatva has language-aware typography. The system auto-detects locale via rememberSystemLanguage() and scales Hindi (Devanagari) fonts +2sp relative to equivalent English styles. Mixed-language strings get per-run styling via String.withMixedTypography().
✅ Mixed-language support: In strings like "हिन्दी English mixed", TatvaText automatically applies the correct font family and size to each run. Latin runs get the English style; Devanagari runs get the Hindi style (+2sp).

Shimmer Modifier
A Modifier extension that overlays an animated diagonal shimmer sweep on any composable. Used for loading skeleton states and as the shimmer effect inside TempleInteractionButton's prompt pill.
// API fun Modifier.shimmer( baseColor: Color? = null, // defaults to schema.neutralElevated durationMillis: Int = 1500 // sweep cycle duration ): Modifier // Usage examples Box(modifier = Modifier.size(200.dp, 16.dp).shimmer()) // skeleton text Box(modifier = Modifier.size(80.dp, 80.dp).shimmer()) // skeleton image Box(modifier = Modifier.shimmer(Color.Purple, durationMillis = 3000)) // custom
The shimmer uses a linearGradient with 3 stops: baseColor@0%, baseColor@100%, baseColor@0%, animating startOffsetX from -2×width to +2×width in an infinite loop.
UI Component — Layout
DraggableView
A full-screen overlay container that allows its content to be freely dragged. When released, it animates back to the initialOffset with a 1000ms spring animation. Does not interfere with click detection on other layers.
@Composable DraggableView( initialOffset: Offset = Offset.Zero, // where to start and return to content: @Composable () -> Unit ) // Usage: floating action button that snaps back DraggableView(initialOffset = Offset(20f, 200f)) { FloatingAartiButton() }
⚠️ DraggableView fills its entire parent (fillMaxSize). The dragged content is bounded within parent constraints and cannot be dragged outside the composable's bounds. Return animation: tween(1000ms).
